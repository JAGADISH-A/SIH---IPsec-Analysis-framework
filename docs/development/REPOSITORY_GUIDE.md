# Repository Guide

How this repository is laid out, how to run it, and what may and may not be
committed. For what the system *does* and what was *verified*, see
[../verification/FINAL_VERIFICATION_REPORT.md](../verification/FINAL_VERIFICATION_REPORT.md).

## Layout

| Path | Contents |
|------|----------|
| `controller/` | Sensor/controller side: capture, strongSwan deployment, dataset generation, feature extraction, RF training/inference, Zeek offline replay. Also holds its co-located `test_*.py`. |
| `correlation/` | Analysis side: expected/observed state, comparison, risk, XAI, audit, response, evidence linkage, and the FastAPI server under `correlation/api/`. |
| `ebpf/` | eBPF/XDP monitor (`xdp_monitor.bpf.c`), the loaded object, generated skeleton header, and state-builder/window-aggregator readers. |
| `configs/` | strongSwan `swanctl` configuration for the four container peers. |
| `topology/` | Containerlab topologies (`tunnel/`, `transport/`). Generated `clab-*` state is ignored. |
| `scripts/` | `install.sh`, `run.sh`, `status.sh`, `stop.sh`, deploy wrappers, traffic generator, traffic validator. |
| `frontend/` | Static dashboard assets served by the API. |
| `campaigns/` | Named experiment plans for `python -m controller.campaign --campaign …`. |
| `campaign.json`, `campaign-quality.json` | Default campaign inputs (kept at root: they are the CLIs' default paths). |
| `tests/` | Analysis-side test suite plus `tests/fixtures/`. |
| `docs/` | All documentation — see [../README.md](../README.md) for the index. |
| `results/` | **Local generated evidence. Not committed** (see below). |
| `out/` | **Generated** dashboard snapshot. Not committed. |

## Environment

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .example.env .env          # local settings; .env is git-ignored
```

Python 3.14.4 with the exact pins in `requirements.txt`.

## Tests

```bash
.venv/bin/python -m pytest -q                     # whole repository
.venv/bin/python -m pytest controller -q          # controller side
.venv/bin/python -m pytest tests -q               # analysis side
```

There is no pytest config file, no packaging metadata and no CI configuration:
tests are plain `unittest`-style modules collected by path.

Some tests exercise **real** committed or local artifacts. Those either skip
cleanly or assert the artifact's presence, so the suite is meaningful both with
and without a populated `results/` tree:

| Artifact | Needed by | Behaviour when absent |
|----------|-----------|-----------------------|
| `controller/testdata/wan_side_esp_ike_sample.pcap` | `controller/test_features.py`, `test_live_features.py`, `test_ml_inference.py` | **Required** — this one *is* committed (2.5 kB), so a fresh clone passes. |
| `results/ml/model_traffic_rf_v1.joblib`, `feature_schema_v2.json` | ML model-contract tests | Skip. |
| `results/observed-state/live_events_full.jsonl`, dataset plan/PCAP | live-correlation, evidence-registration tests | Skip. |

## What `results/` is

`results/` holds ~1.5 GB of real captures, datasets, model artifacts and analysis
output. It is **git-ignored on purpose**: it is machine-local generated evidence,
not source. It is produced by `scripts/run.sh` and the controller dataset/campaign
commands, and it is what the verification reports cite.

The RF model, its training report and the recorded 44-window live run live there,
so `results/` must be regenerated before re-running the real-artifact
verification. The exact commands are in the final verification report's
*Reproduction commands* section.

## Committing rules

Commit:

- source under `controller/`, `correlation/`, `ebpf/`, `scripts/`, `frontend/`
- configuration under `configs/`, `topology/`, `campaigns/`, `campaign*.json`
- tests and committed fixtures, including the one exception to the `*.pcap` rule
- documentation under `docs/`

Do not commit:

- anything under `results/` or `out/`
- `__pycache__/`, `*.pyc`, `.pytest_cache/`, coverage output
- `.env`, keys, certificates
- Containerlab state (`topology/*/clab-*/`)
- `controller/generated/` (regenerated by `controller/generator.py`)

The single deliberate exception is `controller/testdata/*.pcap`, un-ignored in
`.gitignore` because three test modules require it.
